# pure-drop-app

**PureDrop Aqua** - Pure Water Can Delivery & Inventory Management Flutter Application.

## Features
- 🚀 **Admin & Delivery Boy Dashboards**
- 📦 **Order & Inventory Tracking (Filled, Empty, Damaged Cans)**
- 💧 **Water Purchase & Expense Management**
- 👥 **Customer & Employee Salary Management**
- 📊 **Real-time Analytics & Financial Reports**
- 🌐 **Offline Storage (Hive) & Google Apps Script API Backend Integration**
- 📱 **Targeted for Android Platform**

## Getting Started
1. Ensure Flutter SDK is installed.
2. Run `flutter pub get` to fetch dependencies.
3. Connect an Android device or emulator.
4. Run `flutter run` to launch the application.
